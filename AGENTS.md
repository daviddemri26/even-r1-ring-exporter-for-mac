# Even R1 Ring Exporter for Mac development

Use **Even R1 Ring Exporter for Mac** for the Mac application, **Even R1 Ring Data for ChatGPT** for the connector, and **Even R1 Ring Guide for G2 Glasses** for the offline glasses guide.

Use English for documentation, interface text, source identifiers, commit messages, and project filenames, including dotfiles. Preserve required third-party names and exact strings used to recognize localized Even or macOS controls.

Use lists instead of tables. Use synthetic data for development and tests. Keep real ring exports, individual readings, credentials, tunnel profiles, and personal Codex settings outside version control.

Publish the complete English instructions on the project website. Link between guides there. Use real product imagery from an official manufacturer source and credit it. Use the media provider’s supported embed or confirm permission before redistributing a photograph.

The application, runtime, release scripts, website, and glasses guide share this Git repository. For build and test commands, see the [README](README.md).
